Análisis exploratorio de datos de viviendas

Chapter 2 Preparación de los datos

Antes de realizar el análisis exploratorio, es necesario conocer la estructura del conjunto de datos y comprobar que la información se haya cargado correctamente.

2.1 Librerías utilizadas

Para el análisis se utilizarán diferentes paquetes de R que facilitan tanto la manipulación de los datos como su representación gráfica y el cálculo de medidas estadísticas.

library(tidyverse)
library(Amelia)
library(moments)
library(patchwork)
library(GGally)

2.2 Carga del conjunto de datos

El conjunto de datos se encuentra almacenado en un archivo .csv disponible en un repositorio de GitHub. Se utiliza su URL para importarlo a R.

Una vez realizada la importación, se asigna el conjunto de datos al objeto datos, que será utilizado como punto de partida para el análisis.

url <- "https://raw.githubusercontent.com/cdeoroaguado/Datos/main/dataml/housing.csv"
datos <- read.csv(url)

2.3 Tratamiento de valores ausentes

En esta etapa también se debee revisar si existen valores faltantes, ya que estos pueden afectar los cálculos y las observaciones.

Para identificar estos valores se cuenta la cantidad de NA presente por columna:

df <- datos

df %>%
    summarise(across(everything(), ~ sum(is.na(.)), .names = "NA_{.col}"))
##   NA_longitude NA_latitude NA_housing_median_age NA_total_rooms
## 1            0           0                     0              0
##   NA_total_bedrooms NA_population NA_households NA_median_income
## 1               207             0             0                0
##   NA_median_house_value NA_ocean_proximity
## 1                     0                  0

Otra forma de hacerlo es:

missmap(df)

En las variables numéricas que contienen valores faltantes, se utilizará la media de la variable para llenar las ausencias:

df <- df %>%
  mutate(
    across(
      where(is.numeric),
      ~ ifelse(is.na(.), mean(., na.rm = TRUE), .)
    )
  )

Verifiquemos si fueron llenados con el promedio:

df %>%
  summarise(across(everything(), ~ sum(is.na(.)), .names = "NA_{.col}"))
##   NA_longitude NA_latitude NA_housing_median_age NA_total_rooms
## 1            0           0                     0              0
##   NA_total_bedrooms NA_population NA_households NA_median_income
## 1                 0             0             0                0
##   NA_median_house_value NA_ocean_proximity
## 1                     0                  0

Ya que se ha confirmado que no quedan valores NA, el conjunto de datos está preparado para continuar con el análisis exploratorio.
